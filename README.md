# 白板接入验证（开发中）

用于验证外部插件在 Tau 白板中创建、编辑和保存方块。它是火柴人迁移前的 M1 验证样本，不是完整火柴人插件。

已完成 M1 的独立构建与隔离 Electron 行为验收。需要运行包含白板插件接入实现的开发客户端；当前不面向正式用户发布。

M2 已补充角点等比缩放、箭头连接、手绘模式与缩略图。拖动后可撤销/重做，取消缩放会恢复起始尺寸；图层名称来自插件声明。

在开发客户端安装 `dist/example.whiteboard-probe-0.2.0.zip`，启用并完整重启。打开白板，从「扩展工具」选择「验证方块」，单击画布放置；选中后可用属性栏修改文字，并测试撤销、重做、复制和保存重开。0.2.0 可通过正常升级流程替换 M1 的 0.1.0 验证包。

SDK 采用本地生成的开发声明包，位于 `.sdk/`，不包含宿主运行时实现。其他依赖来自公开 npm。已有 dist 中的计数器 ZIP 属于早期模板基线，不是本插件。
