# 火柴人

在白板上放上小人，用来表达动作、情绪、工作场景和团队关系，让流程图、示意图更生动。有经典、豆豆、象形三种造型，可以单色或加点缀色，也能左右翻转。

## 开始使用

1. 在插件中心安装「火柴人」，装好后完全退出 Tau 再重新打开。
2. 打开白板，在「扩展工具」里选择「人物」，挑一个姿势，再点一下画布放上去。
3. 选中人物后，在属性栏里换姿势、造型、配色，或者左右翻转。

## 可以做什么

- 拖动四个角等比缩放，也能用箭头把人物和其他图形连起来。
- 跟着白板的画风走，也可以在「笔触」里单独换成手绘风格、调整笔触强度。
- 新放的人物会沿用你上次选的造型和配色。
- 支持复制、撤销、重做，导出白板图片时人物也会一起导出。

## 常见问题

**停用插件后人物去哪了？** 会先显示成一个占位，重新启用后恢复原样，不会丢。

**换了工作区，造型偏好怎么变了？** 每个工作区单独记住自己的偏好。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 启用、停用或升级插件后，要完全退出 Tau 再打开才会生效。
