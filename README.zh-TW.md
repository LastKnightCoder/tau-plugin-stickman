# 火柴人

在白板上放置小人，用來表達動作、情緒、工作場景與團隊關係，讓流程圖、示意圖更生動。提供經典、豆豆、象形三種造型，支援單色或加上點綴色，也能左右翻轉。

## 開始使用

1. 在外掛中心安裝「火柴人」，再到外掛頁的「已安裝」裡開啟開關，接著點擊外掛頁頂部提示列上的「立即重啟」，重新啟動後即可使用。
2. 開啟白板，在「擴充工具」裡選擇「人物」，挑選一個姿勢，再點一下畫布放上去。
3. 選取人物後，可在屬性列中切換姿勢、造型、配色，或左右翻轉。

## 可以做什麼

- 拖曳四個角即可等比例縮放，也能用箭頭將人物與其他圖形連起來。
- 跟隨白板的畫風，也可以在「筆觸」裡單獨切換為手繪風格並調整筆觸強度。
- 新放置的人物會沿用你上次選擇的造型與配色。
- 支援複製、復原、重做，匯出白板圖片時人物也會一併匯出。

## 常見問題

**停用外掛後人物去哪了？** 會先顯示為一個佔位框，重新啟用後恢復原樣，不會遺失。

**切換資料庫後，造型偏好怎麼變了？** 每個資料庫會各自記住自己的偏好設定。

## 小提醒

- 開啟、關閉或升級此外掛後，都必須重新啟動 Tau 才會生效，外掛頁會提示「立即重啟」。
